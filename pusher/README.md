# Пушер — Web Push о новых заявках в дашборд

Отдельная функция Yandex Cloud. **Работающую систему не трогает:** основная функция,
YDB, GAS → Telegram и CreatorHub не меняются. Пушер только читает заявки
(`GET ?r=orders`, как дашборд) и ничего никуда не пишет.

## 1. VAPID-ключи (один раз)

На компьютере: `npx web-push generate-vapid-keys`.
Получите Public Key и Private Key. Приватный — никому, в репозиторий не класть.

## 2. Подписка iPhone

Дашборд на экране «Домой» (iOS 16.4+) → Настройки → Уведомления →
вставить Public Key → «Включить» → разрешить → «Скопировать подписку».

## 3. Функция

Cloud Functions → Создать функцию `dashboard-pusher` → Node.js 18 →
файлы `index.js` и `package.json` из этой папки, точка входа `index.handler`, таймаут 10 с.

Переменные окружения (секретные лучше через Lockbox):

| Переменная | Значение |
|---|---|
| `ORDERS_URL` | `https://functions.yandexcloud.net/d4e2uuvutkn0qcqevb9j` |
| `API_KEY` | ключ, который вводится в дашборде |
| `VAPID_PUBLIC` / `VAPID_PRIVATE` | из шага 1 |
| `VAPID_SUBJECT` | `mailto:ваша@почта` |
| `PUSH_SUBSCRIPTION` | JSON из шага 2 целиком |

Нажмите «Тестировать»: ответ `нет новых` — связь с облаком есть.

## 4. Таймер

Триггеры → Создать → Таймер → cron `* * * * ? *` → функция `dashboard-pusher`
(сервисный аккаунт с ролью `functions.functionInvoker`).

## Проверка и откат

- Оставьте заявку с сайта — пуш придёт в течение минуты, Telegram как прежде.
- В логах `push 403/400` — проблема с ключами; `push 410` — включите пуши заново и обновите `PUSH_SUBSCRIPTION`.
- Ошибка соединения с `web.push.apple.com` — значит, Яндекс не достаёт до Apple; тот же код можно поднять в другом облаке.
- **Откат:** выключить или удалить таймер. Больше ничего делать не нужно.
