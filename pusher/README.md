# Пушер — Web Push о новой заявке в дашборд

Подстраховка к Telegram. Отдельная функция Yandex Cloud, которую будит **GAS** сразу после
отправки в Telegram — один вызов на одну заявку.

**Ничего существующего не меняет:** `hub-api`, YDB, `cm-*`, формы сайтов и отправка в Telegram остаются как были.
Пушер не обращается ни к облаку, ни к базе — получает от GAS только тип и источник
и пересылает в Apple. Если упадут и GAS, и пушер — заявка всё равно лежит в Заявках.

## 0. Проверка связи с Apple (если ещё не делали)

Функция `push-test`, Node.js 18:

```js
module.exports.handler = async () => {
  try {
    const r = await fetch('https://web.push.apple.com/', { method: 'POST' });
    return { statusCode: 200, body: `✅ Apple доступен (ответ ${r.status})` };
  } catch (e) {
    return { statusCode: 200, body: `❌ Нет связи с Apple: ${e.message}` };
  }
};
```

«Тестировать» → ✅ с любым кодом — продолжаем; ❌ — в Яндексе не выйдет. После — удалить.

## 1. VAPID-ключи (один раз)

На компьютере: `npx web-push generate-vapid-keys`. Приватный ключ — никому и не в репозиторий.

## 2. Подписка iPhone

Дашборд с экрана «Домой» (iOS 16.4+) → Настройки → Уведомления →
вставить Public Key → «Включить» → разрешить → «Скопировать подписку».

## 3. Функция

Cloud Functions → **Создать функцию** `dashboard-pusher` → Node.js 18 →
файлы `index.js` и `package.json` из этой папки, точка входа `index.handler`,
память 128 МБ, таймаут 5 с.

Переменные окружения:

| Переменная | Значение |
|---|---|
| `VAPID_PUBLIC` / `VAPID_PRIVATE` | из шага 1 |
| `VAPID_SUBJECT` | `mailto:ваша@почта` |
| `PUSH_SUBSCRIPTION` | JSON из шага 2 целиком |

Обзор функции → включить **«Публичная функция»** (форма вызывает её без ключа, как GAS).
Скопировать ссылку вида `https://functions.yandexcloud.net/d4e…`.

Проверка: вкладка «Тестирование», тело запроса
`{"httpMethod":"POST","body":"{\"type\":\"Тест\",\"source\":\"github\"}"}` → на iPhone приходит пуш.

## 4. GAS

В проект GAS («Мои пуши в телегу») только добавляется: строка `notifyPusher_(type, source);`
в `doPost` сразу после `sendTelegram_(…)` и функции `notifyPusher_` / `testDashboardPush` в конце.
Публикация — «Управление развёртываниями» → карандаш → «Новая версия» (адрес Web App не меняется).
Формы сайтов не трогаются.

## Лимиты и откат

- Один вызов ≈ 0,1 с × 128 МБ на заявку — далеко внутри бесплатного лимита.
  Защита от чужих вызовов: не больше 20 пушей за 10 минут.
- Ответ пушера: `sent 201` — Apple принял; `err:410` — включите пуши в дашборде заново и обновите `PUSH_SUBSCRIPTION`.
- **Откат:** убрать строку `notifyPusher_` в GAS (новая версия того же развёртывания) и удалить функцию.
